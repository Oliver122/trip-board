# Core — Ops

How the repo is built, run, checked and shipped: the dev setup and scripts, configuration and health, the database (migrations, checks, seed, test databases), server hardening that applies to every route, housekeeping jobs, the CI pipeline and its end-to-end matrix, the deploy to production, local dev login settings, e2e stability rules, the texture atlas tooling, and the UI review run and its report. Login behavior is in [auth](./auth.md), the web side of errors and hardening in [app](./app.md), and the kinds whose symbols the textures decorate in [kinds](./kinds.md). The requirements process itself (core files, index, `pnpm req:check`) is added by step 30.
